Drama 3 for ComfyUI - original FP8 with RAM offloading

Start with README.md or README.fr.md.
The workflows folder contains 16 ready-to-load examples.
The examples folder contains generated audio, synthetic starter references,
a reusable synthetic take, and measured validation results.

The local runtime is configured through runtime.json (not included in public Git).
The model checkpoint remains in the configured model folder, normally D:\Models\drama-3.
This integration does not modify ComfyUI's Python dependencies.
